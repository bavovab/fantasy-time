# Fantasy Time

Архив независимого аналитического и fantasy-проекта по Dota 2 и The International 2026.

> Разработка и обновление данных приостановлены 25 августа 2026 года. Сайт [fantasy-time.online](https://fantasy-time.online) сохранён как статический снимок последнего состояния.

## Что находится в репозитории

- работающий статический снимок сайта для GitHub Pages;
- обезличенные публичные данные, использовавшиеся последней опубликованной версией;
- исходный код сервисов в каталоге `source/`;
- описание архитектуры в [ARCHITECTURE.md](ARCHITECTURE.md);
- список сторонних компонентов и атрибуций в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Приватные базы данных, реплеи, Steam-сессии, ключи, токены и серверные конфигурации в репозиторий не входят.

## Архитектура в двух словах

Матчи собирались агентами Dota GC и live-наблюдателями, обрабатывались локальным сервисом, а затем экспортировались в безопасный статический набор JSON и медиафайлов. Отдельный издатель фиксировал этот набор в GitHub Pages. После остановки фоновые агенты и издатель выключены, поэтому размещённый сайт не обращается к приватному серверу.
