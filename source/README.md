# Исходный код

Этот каталог содержит архивную копию исходного кода Fantasy Time без рабочих данных и секретов.

Опубликованные компоненты:

- `DotaLocalHub` — локальный API, хранение и разбор матчей;
- `DotaGcAgent` — шлюз Dota Game Coordinator;
- `DotaLive` — live-координатор и наблюдатели;
- `DotaClientInstaller` — установка клиента Dota 2;
- `DotaPublic` — фильтрация, статический экспорт и публикация;
- `Dota` — интеграция состояния сервисов в Salfetka Hub.

Операционные файлы Compose, серверные адреса, `data/`, `secrets/`, реплеи, Steam-сессии, ключи, кэши и собранные бинарные файлы намеренно не публикуются. Для полноценного восстановления используется отдельный приватный бэкап.

Исходный код предоставлен как исторический снимок проекта. Сторонние компоненты и материалы продолжают использоваться на условиях их собственных лицензий; см. [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).
