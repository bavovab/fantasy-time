# Архитектура Fantasy Time

## Поток данных

1. `DotaGcAgent` получал метаданные профессиональных матчей через Dota Game Coordinator.
2. `DotaLive` использовал отдельные аккаунты-наблюдатели для получения live-состояния матчей.
3. `DotaLocalHub` хранил локальную базу, разбирал реплеи и рассчитывал статистику и fantasy-очки.
4. `DotaPublic` фильтровал приватные поля, зеркалировал разрешённые изображения и формировал статический снимок API.
5. Publisher собирал автономный сайт и отправлял его в GitHub Pages.

## Компоненты

| Компонент | Назначение |
| --- | --- |
| `DotaLocalHub` | локальный API, база матчей, разбор реплеев и расчёты |
| `DotaGcAgent` | ограниченный шлюз к Dota Game Coordinator |
| `DotaLive` | координатор и live-наблюдатели |
| `DotaClientInstaller` | воспроизводимая установка клиента Dota 2 для наблюдателей |
| `DotaPublic` | публичный экспорт, статический сервер и GitHub publisher |

## Состояние архива

На 25 августа 2026 года фоновые компоненты остановлены. GitHub Pages содержит последний экспортированный статический снимок и не требует доступа к домашнему серверу, Docker, Steam или Dota Game Coordinator.

Приватный восстановительный архив хранится отдельно от GitHub. В него входят серверные исходники, конфигурация, базы, служебные состояния и секреты. Загружаемый заново клиент Dota 2 не дублируется в публичном репозитории.

## Безопасность публикации

В `source/` разрешены только исходники и общая документация. Следующие данные намеренно исключены:

- `data/`, базы SQLite и реплеи;
- `secrets/`, ключи развертывания и токены;
- Steam-сессии и учётные данные наблюдателей;
- локальные адреса и файлы окружения;
- кэши сборки и загруженный клиент Dota 2.
